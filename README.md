# Страховая компания: desktop-приложение

Курсовой проект по базам данных: «Разработка клиент-серверного desktop-приложения для поддержки бизнес-процессов компании». Приложение для страховой компании с филиалами, агентами, клиентами и договорами страхования.

## Возможности

- Регистрация и вход с тремя ролями: администратор, страховой агент, клиент.
- Администратор: просмотр, добавление, изменение и удаление данных о филиалах, агентах, клиентах, договорах, видах страхования и пользователях.
- Агент: личный кабинет, список своих клиентов и договоров, поиск и фильтрация по фамилии.
- Клиент: личный кабинет с данными профиля и своими договорами.
- Расчёт вознаграждения агента: процент от страхового платежа (страховая сумма, умноженная на тарифную ставку).

## Структура

- `src/main/java/ru/mypackage/`: код приложения по схеме MVC (`model`, `view`, `controller`, `database`).
- `database/schema.sql`: создание базы данных и таблиц, тестовые данные.
- `docs/`: пояснительная записка (PDF): модели базы данных, описание реализации и сценарии работы.
- `pom.xml`: описание проекта для Maven (версия Java, библиотеки JavaFX и драйвер MySQL, запуск).

## Технологии

Java 23, JavaFX, JDBC, MySQL, Maven.

## Запуск

1. Установить JDK 23 и XAMPP (в нём есть MySQL), затем установить IntelliJ IDEA.
2. В панели XAMPP нажать Start напротив MySQL.
3. Открыть в браузере phpMyAdmin (`http://localhost/phpmyadmin`), перейти на вкладку «Импорт», выбрать файл `database/schema.sql` и нажать «Вперёд». Создаётся база `Insurance company` с тестовыми данными.
4. В IntelliJ IDEA открыть папку проекта (File → Open, папка с файлом `pom.xml`) и дождаться загрузки зависимостей Maven.
5. Справа открыть вкладку Maven, раскрыть Plugins → javafx и дважды щёлкнуть по `javafx:run`. Откроется окно авторизации.

Вместо шагов 4–5 можно запустить приложение из командной строки в папке проекта (нужен установленный Maven): `mvn javafx:run`.

Параметры подключения к базе данных находятся в `ConnectionDatabase.java` (по умолчанию стандартные для XAMPP: пользователь `root`, пароль пустой).

Тестовые учётные записи (логин и пароль): `admin` / `a`, `agent1` / `1`, `client1` / `c`.
